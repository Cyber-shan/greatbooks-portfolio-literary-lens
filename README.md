# Portfolio

Run `npm run dev`, then open http://localhost:4173. The static website is in `dist/`. No dependencies are required.

The site uses the Heritage Study theme and the supplied portrait. Published writing in `dist/content.js` takes precedence over backups from the retired browser editor; stored backups are retained. The favorite discussion, profile, learning notes, and reflections use Shan Paul's supplied points about persistence, learning technology, and checking applications.

See [the personal writing revision notes](docs/personal-writing-revision.md) for the editorial scope and source basis. The website's Sources & credits dialog identifies assistance. Course authorship requirements and the student's own review remain relevant to submission.
